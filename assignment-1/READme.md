# Interactive Story Builder

An interactive web app inspired by a classic children's toy, built with vanilla JavaScript. Users click through buttons to cycle and combine phrases into a complete story.

## Features
- Phrase cycling via event listeners and DOM manipulation
- String concatenation logic to build full sentences from selected phrases
- Randomization feature to auto-select mixed phrase combinations
- Responsive interface built with CSS Flexbox, styled to mimic the original toy's layout

## Tech Stack
HTML, CSS, JavaScript
